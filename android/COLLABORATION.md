# 协作模式（0.9.0-alpha 首版）

## 开始使用

1. 在设置中完成共享环境初始化、Agent 安装和官方 / 第三方 API 配置，并启动要使用的 Agent。
2. 从左侧菜单打开“协作”；也可以在现有会话顶部点击“独立 ▾”，把该会话作为协作背景。当前任务未结束时，可等待完成或中断后进入。
3. 新建协作，填写目标与项目目录，添加参与者。参与者可以使用相同 Agent 的不同模型，也可以混用 Codex、Claude Code、DeepSeek。分别设置职责、模型、思考强度、权限及 API 来源。
4. 添加子任务，指定参与者、依赖、交付标准及需要的重任务 / 手机 / 浏览器资源。不设置依赖的任务可并行；同一参与者自身仍按顺序执行，需要同 Agent 并行时添加另一参与者。
5. 保存计划。可手动编辑，也可让负责人调用模型生成 JSON 计划提案；提案必须通过依赖和分配校验，生成失败保留原草稿。检查后点击“确认计划并开始”。
6. 在详情查看进度、请求、用量和结果。停止一个子任务不停止其他实例；暂停只停止新派发。全部完成后人工检查成果并验收。

保存草稿和模式切换不调用模型，生成计划或执行任务会产生对应 API 用量。模型选择列表来自该 Agent 当前配置；选择其他 API 来源时可手填其模型 ID。首版来源是当前 / 官方 API / 第三方 API 三种，尚无额外具名来源库。

## 项目与产物

Git 项目必须选择仓库根目录、具有提交且没有未提交修改。每次尝试创建独立 worktree，依赖补丁带入新工作区；即使 Agent 在自己的工作区提交代码，交付补丁仍与起始基线比较，包含新增文件。

补丁不会自动写入原项目。在任务详情明确选择合入，系统核对原项目仍干净且 HEAD 未变化，并先运行 `git apply --check`；应用后不自动提交。多个依赖补丁可能冲突，冲突时停止该次执行，保留隔离目录供检查。首版不自动解决复杂分支的累计补丁冲突。一个补丁已合入后原项目变脏，后续补丁需检查后手动合并或提交并重新规划。

非 Git 项目复制不超过 200 MiB 的快照，跳过 `.git`、`.state`、`node_modules`、`.gradle`、`build` 和 `__pycache__`，拒绝符号链接。依赖成果可以按文本交接；文件成果在各任务工作区内查看和手动提取。排除的依赖 / 构建缓存需要任务自行准备。

工作区隔离不是操作系统安全沙箱，不能阻止 Agent 通过任意绝对路径、外部 MCP 或网络修改其他位置。参与者默认询问权限，自动执行须主动选择。

## 改派、切换和恢复

子任务可更换 Agent / 模型。执行中可选择当前任务继续、仅保存下次配置，或先中断旧实例、确认退出后再派给新配置；旧尝试、工作区、日志和用量保留。重试会新建一次尝试，成功的下游任务会标记为失效并重新等待依赖；不会自动重复失败任务。

回到独立模式保留原会话 ID。协作可在后台继续，也可中断后返回；同项目独立任务等待协作释放项目锁。已完成成果通过交接记录进入原会话，未合入修改会明确标记。原会话忙碌时不注入当前 CLI，结束后可在协作详情点击“接收最新成果到原会话”。

服务重启后暂停协作，不自动重放模型请求或工具调用；排队的普通消息标记为中断，输入保留。旧执行仍存活或退出状态不确定时，任务进入“待核对状态”；核对后还需确认已记录进程退出，才可恢复。无法保证追踪所有主动脱离原进程组的外部子进程。

## 名额、工具和统计

所有 App 普通会话与协作执行共享全局名额，默认 2；重任务最多 1。同 API 网关按 URL 的协议和主机端口归组，默认 2 个并发，可设 1 / 2 / 3。普通适配器本身仍一次一个，独立协作 worker 可与它并行。旧的原始 CLI 提交入口在协作占用资源时拒绝绕过调度。

资源信息超过 20 秒、Android 报告低内存、可用内存低于 1 GiB、热状态达到严重级别时暂停新派发；不假装冻结正在执行的 CLI。停止 Agent 会先暂停相关流程并中断其活动协作实例；协作不会静默启动被手动关闭的 Agent。

内置手机和开发浏览器工具仅在预留对应独占资源的任务内开放。协作不能修改共享扩展，扩展在启动时按 Agent 启用范围复制快照；第三方外部 MCP 工具没有全面的资源分类限制。

提问和权限请求按工作流、子任务、尝试和原生请求编号路由，避免两个实例使用相同原生编号时串答。实例结束会撤销相关待回答问题，停止普通会话不取消后台协作问题。

每次尝试保留原始用量并汇总到主会话，切换模式不清空。DeepSeek 当前 ACP 的上下文占用不冒充累计计费 Token；未报告的用量显示缺失，不按零计算费用。执行日志与诊断保存在私有目录，显示前脱敏，事件和诊断文件各约 1 MiB 轮转上限。
