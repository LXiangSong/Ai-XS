# 删除会话后端契约

`native/chat/thread/delete` 保留参数 `{ "threadId": "…" }`，成功返回 `{ "deleted": true, "threadId": "…", "nativeSessionsDeleted": 3 }`。只有实际清理完成才成功；运行中 / 原生删除失败 / 文件清理失败返回原来的错误通道，前端不能提前移除会话或提示成功，可以重试。

删除范围：该会话的共享历史文件、上下文与 Token 快照、关联的 Codex / Claude / DeepSeek 原生历史、没有其他会话引用的协作工作流、全部尝试的隔离环境、保存的执行凭据、过程日志、补丁和上传附件。Codex 使用其官方 `thread/delete` 协议；Claude / DeepSeek 按原生会话 ID 清理对应历史目录。协作数据库实际删除记录并清理 WAL。索引仅保留不含标题、消息、提示词或统计的 ID 删除标记，防止旧缓存把记录重新列出。

用户项目目录和项目源码保留。已创建的分叉 / 编辑前备份是独立会话，其消息和仍引用的协作执行、附件保留；共享执行会归属到存活的会话，最后一个引用删除时清理。已有运行任务需先停止并确认退出。

前端已按此契约接入：确认文案为“将删除本会话的消息、原生 Agent 历史和关联执行数据。项目文件及独立分叉会话保留。”，成功提示为“会话已删除”，并同步清理页面缓存、抽屉条目和当前会话草稿。服务启动时会在后台补清旧版本遗留的未完成删除记录，失败项保留下次启动重试。
